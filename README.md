# 🤖 Job Hunter Telegram Bot

Интеллектуальный бот для автоматизации поиска работы и отправки откликов. Проект разработан для автоматизации рутинных процессов поиска, анализа вакансий и написания персонализированных сопроводительных писем.

---

## 🏗 Архитектура проекта

Проект построен по модульному принципу:

* **`app.js`**: Главный контроллер, управляющий циклом автоматизации.
* **`src/bot/`**: Интеграция с Telegram (Telegraf), обеспечивающая удаленное управление ботом.
* **`src/browser/`**: Автоматизация браузера на базе `Puppeteer`. Отвечает за навигацию, парсинг и взаимодействие с интерфейсом сайта.
* **`src/services/`**: Интеграция с LLM (искусственным интеллектом) для генерации текстов.
* **`src/database/`**: Слой работы с базой данных (MySQL) для отслеживания статусов вакансий.

## 🛠 Установка и запуск

### Требования

* **Node.js** (версии 18 и выше)
* **MySQL Server**

1. **Клонирование репозитория:**

## 🔑 Получение API ключей

Для работы бота требуются ключи от сервиса **OpenRouter**. Он предоставляет доступ к бесплатным и платным моделям ИИ без блокировок по ГЕО (РФ/РБ).

1. Перейдите на сайт [OpenRouter.ai](https://www.google.com/url?sa=E&q=https%3A%2F%2Fopenrouter.ai%2F).
2. Зарегистрируйтесь и перейдите в раздел **"Keys"**.
3. Нажмите **"Create Key"**.
4. Скопируйте полученный ключ (начинается на `sk-or-v1-...`).
5. Вставьте его в ваш `.env` файл в переменную `OPENROUTER_API_KEY`.

## 🤖 Команды управления (в Telegram)

После запуска бота, используйте следующие команды в вашем личном чате:

* `/run` — запуск процесса мониторинга вакансий.
* `/stop` — безопасная остановка текущего цикла.
* `/status` — проверка работоспособности бота.

## 📋 Используемый стек

В проекте используются следующие технологии:

* 🟢 **Node.js** — среда, в которой запускается приложение.
* 🌐 **Puppeteer + puppeteer-extra** — автоматизация браузера: бот может открывать страницы, переходить по ним, находить нужную информацию и взаимодействовать с сайтом.
* 🤖 **OpenAI API (OpenRouter)** — подключение к моделям искусственного интеллекта для анализа вакансий и генерации текстов.
* 🗄️ **MySQL + mysql2** — база данных, в которой хранится информация о вакансиях и их текущих статусах.
* 💬 **Telegraf API** — позволяет управлять ботом через Telegram и получать информацию о его работе.
